SIM Campus Timetable

The campus schedule, but useful — filter by block, floor and room, or flip to availability mode to find rooms that are actually free. Updated automatically every day just after midnight.

You probably don't need to do anything

The viewer refreshes itself every day at about 00:05, so it already has today's schedule — including every room with nothing booked in it at all.

Read it straight from SIM's own campus API, so it covers all 326 rooms rather than only the ones that happen to be busy.

Want it right now instead?

Use the bookmarklet below if you need the very latest state mid-day rather than last night's snapshot.

  1. Drag the bookmarklet to your bookmarks bar — once, ever.
  2. Open the scheduling page and click it.
  3. It opens the viewer and hands today's schedule over in about a second.

Prefer the console? Copy the script and paste it into DevTools (F12) on the scheduling page instead — same result. If the viewer tab gets popup-blocked, it falls back to downloading sim-timetable.json for you to drop into the viewer.

It runs in your browser because SIM's API only answers requests from its own page. Nothing is uploaded anywhere — this site is static, and the data goes straight from the scheduling tab to your viewer tab.
